N.C.L.B

NO · CHILD · LEFT · BEHIND

Ouvre cette page dans Safari sur l'iPhone : les autres navigateurs ne peuvent pas installer le profil.

Ce que fait N.C.L.B

Plusieurs couches de protection, qui se renforcent les unes les autres.

  • Sites pornographiques bloqués dans toutes les apps (filtre DNS NextDNS).
  • t.me / Telegram bloqué.
  • Reddit et X restent accessibles, avec leur contenu NSFW masqué (étape 4).
  • Téléchargement d'apps verrouillé : aucune app ne peut être installée sans le code de ton formateur. Navigateurs Tor, apps dark web et apps de rencontre : impossibles à télécharger.
  • .onion : inaccessibles. Ces adresses ne fonctionnent qu'à travers une app Tor, et aucune ne peut être installée.
  • Sites de rencontre bloqués par le filtre.
  • Journal des sites bloqués, consultable à distance par ton formateur.
  • Les VPN restent autorisés. Pour en installer un nouveau, ton formateur déverrouille le téléchargement le temps de l'installer.

Tes options

Les étapes ci-dessous s'adaptent à tes choix.

Comment utiliser Reddit et X ?

1Ton formateur crée le filtre

C'est ton formateur qui crée le compte NextDNS (gratuit) et garde le mot de passe. Il verra le journal et sera le seul à pouvoir changer les règles.

  1. Sur son téléphone ou son ordinateur : my.nextdns.io → créer un compte.
  2. Onglet Parental Control → Categories : activer Porn et Dating. Activer aussi SafeSearch et YouTube Restricted Mode.
  3. Ne pas activer « Block Bypass Methods » : cette option bloquerait les VPN.
  4. Onglet Denylist : ajouter un par un chaque domaine ci-dessous (touche-le pour le copier).
  5. Onglet Settings → Logs activés, conservation la plus longue possible.
  6. Onglet Setup : noter l'ID (6 caractères) et te le donner.
.onion : ajoute d'abord *.onion. Si NextDNS refuse, passe au suivant : les adresses .onion ne s'ouvrent jamais sans app Tor, et le verrou de téléchargement (étape 3) rend ces apps impossibles. Les domaines onion.ly, onion.ws, onion.pet, onion.to, onion.link et tor2web.org bloquent les passerelles : les seuls sites qui permettent d'ouvrir le dark web depuis Safari, sans app Tor. ahmia.fi et dark.fail sont des annuaires du dark web. redgifs.com héberge une grande partie des vidéos NSFW de Reddit. Les sites de rencontre sont bloqués par la catégorie Dating, sans rien taper.
Pas de formateur avec NextDNS ? Filtre de secours sans compte

Moins complet : pas de journal, et ni t.me ni les sites de rencontre ne seront bloqués par ce filtre. Temps d'écran (étape 3) pourra les bloquer dans Safari.

2Installe la protection

Télécharge le profil, puis valide-le dans Réglages.

  1. Safari demande l'autorisation de télécharger un profil → Autoriser.
  2. Réglages → Profil téléchargé (en haut) → Installer → code de l'iPhone → Installer.
  3. Réglages → Général → VPN et gestion de l'appareil → DNS : vérifier que N.C.L.B est coché.
Rien ne se passe ? App Fichiers → Téléchargements → touche NCLB.mobileconfig.

3Verrouille avec Temps d'écran

La couche qui tient même avec un VPN.

  1. Réglages → Temps d'écran → activer. Puis Contenu et confidentialité → activer l'interrupteur.
  2. Restrictions de l'App Store et d'iTunes (ou « Restrictions de contenu ») → Apps → choisir la limite juste en dessous de la plus haute (16+ ou 12+ selon la version d'iOS). Les apps 17+/18+ (rencontres, Tor, Telegram, apps Reddit et X) disparaissent et ne peuvent plus être téléchargées.
  3. Restrictions de l'App Store et d'iTunes → Apps : laisser toutes les apps autorisées, pour garder Reddit et X (déjà installées).
  4. Contenu et confidentialité → Achats dans l'iTunes et l'App Store → Installation d'apps → Ne pas autoriser. C'est le verrou qui rend impossible le téléchargement de navigateurs Tor et d'apps dark web.
  5. Même écran → Contenu web → Limiter les sites pour adultes.
  6. Sous Ne jamais autoriser, ajouter : redgifs.com, onion.ly, onion.ws, tor2web.org, torproject.org, t.me.
  7. Laisser « Applications VPN » autorisées : tes VPN déjà installés continuent de fonctionner.
  8. Retour à Temps d'écran → Utiliser un code Temps d'écran : ton formateur le tape et le garde.
Installer une nouvelle app plus tard (un VPN, par exemple) : ton formateur va dans Installation d'apps → Autoriser avec son code, tu installes l'app, puis il remet Ne pas autoriser. Il voit ainsi chaque app installée.
Vérification : ouvre l'App Store et essaie de télécharger n'importe quelle app gratuite. Le bouton doit être bloqué. Sinon, le verrou n'est pas actif.

4Reddit et X sans NSFW

Ces réglages se font dans chaque compte. Ton formateur les active avec toi.

  1. Reddit : Paramètres → Préférences → désactiver « Afficher le contenu pour adultes (18+) » et activer le floutage des images NSFW.
  2. X : Paramètres → Confidentialité et sécurité → Contenu que vous voyez → décocher « Afficher les médias susceptibles d'être sensibles ».
  3. X : même écran → Paramètres de recherche → activer « Masquer le contenu sensible ».
  4. Ne suivre aucun compte ni subreddit NSFW, et ne rejoindre aucune communauté marquée 18+.
  5. Facultatif, mais le plus solide : ton formateur change le mot de passe de ces comptes et le garde. Ces réglages ne peuvent alors plus être réactivés en cachette.
Les menus exacts peuvent changer selon les versions de Reddit et X. Ces réglages masquent la grande majorité du NSFW, pas la totalité.

5Le journal pour ton formateur

Chaque tentative bloquée est enregistrée avec la date, l'heure, le domaine et la raison.

  1. Ton formateur ouvre my.nextdns.io → onglet Logs.
  2. Il active le filtre « Blocked Queries Only » : seules les tentatives bloquées s'affichent, avec leur raison (Porn, Dating, Denylist…).
  3. Il peut ajouter la page à l'écran d'accueil de son téléphone pour la consulter en un geste.
Le journal est stocké chez NextDNS (pas dans ton iPhone), sinon ton formateur ne pourrait pas le consulter. Pendant qu'un VPN est connecté, rien n'y apparaît.

6Teste la protection

Entre un domaine qui devrait être bloqué, par exemple t.me. Wikipédia sert de témoin pour vérifier qu'Internet fonctionne. Refais le test avec ton VPN connecté.
