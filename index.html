    NavigateursBrowsers

    Chrome et Firefox peuvent contourner le filtre avec leur propre « DNS sécurisé ». Désactivez-le : Chrome → Paramètres → Confidentialité et sécurité → Sécurité → Utiliser un DNS sécurisé : désactivé. Firefox → Paramètres → Vie privée et sécurité → DNS via HTTPS : désactivé.

    Chrome and Firefox can bypass the filter with their own "secure DNS". Turn it off: Chrome → Settings → Privacy and security → Security → Use secure DNS: off. Firefox → Settings → Privacy & Security → DNS over HTTPS: off.

    Étape 4Step 4 Verrouiller l'appareil et bloquer TorLock down the device and block Tor Empêche de supprimer le filtre ou d'installer des apps.Prevents removing the filter or installing apps.
    Important. Aucun filtre ne peut voir à l'intérieur d'un navigateur Tor (Onion Browser, Orbot, Tor Browser…). La seule protection contre le dark web consiste à supprimer ces apps et à empêcher leur réinstallation.
    Important. No filter can see inside a Tor browser (Onion Browser, Orbot, Tor Browser…). The only protection against the dark web is to delete these apps and prevent them from being reinstalled.
    1. Supprimez toute app Tor : appui long sur l'icône → Supprimer l'app. Recherchez aussi « Tor », « Onion » ou « Dark » dans le nom des apps.
    2. Réglages → Temps d'écran → Contenu et confidentialité → activez l'interrupteur.
    3. Restrictions de contenu (App Store, médias, web et jeux) → Contenu web → Limiter les sites pour adultes.
    4. Achats sur l'App Store → Installation d'apps → Ne pas autoriser. L'App Store disparaît : plus aucune app ne peut être installée ni réinstallée, y compris une app Tor déjà supprimée.
    5. Retour à Temps d'écran → Verrouiller les réglages de Temps d'écran : le formateur choisit le code et le conserve.
    1. Delete every Tor app: long-press the icon → Remove App → Delete App. Also look for "Tor", "Onion" or "Dark" in app names.
    2. Settings → Screen Time → Content & Privacy Restrictions → turn it on.
    3. App Store, Media, Web & Games → Web Content → Limit Adult Websites.
    4. App Store Purchases → Installing Apps → Don't Allow. The App Store disappears: no app can be installed or reinstalled, including a Tor app that was already deleted.
    5. Back to Screen Time → Lock Screen Time Settings: the trainer sets the passcode and keeps it.
    1. Supprimez toute app Tor (Tor Browser…) : glissez-la dans la Corbeille, puis videz-la.
    2. Mac : Réglages Système → Temps d'écran → Contenu et confidentialité → activez l'interrupteur.
    3. Restrictions du Store → Apps → 12+. Restrictions de contenu → Accès au contenu web → Limiter les sites pour adultes.

    Étape 5 · facultatifStep 5 · optional Maintenir la protection avec NordVPNKeep the protection with NordVPN Seulement si NordVPN est utilisé sur l'appareil.Only if NordVPN is used on the device.

    Lorsqu'un VPN est connecté, il remplace le filtre. Ce réglage unique, effectué par le formateur, fait passer NordVPN par N.C.L.B : le blocage et le journal restent actifs avec le VPN.

    When a VPN is connected, it replaces the filter. This one-time setup, done by the trainer, routes NordVPN through N.C.L.B: blocking and the log keep working with the VPN on.

    1. NextDNS : Setup → Linked IP. Notez l'adresse IPv4 et copiez l'Update URL (sous « Show advanced options »). Ce lien doit rester privé.
    2. NordVPN : désactivez Protection contre les menaces (Threat Protection).
    3. Paramètres → DNS personnalisé → activez-le et saisissez l'adresse IPv4 de NextDNS.
    4. Connectez toujours NordVPN au même serveur (pas « Connexion rapide »).
    1. NextDNS: Setup → Linked IP. Note the IPv4 address and copy the Update URL (under "Show advanced options"). Keep this link private.
    2. NordVPN: turn off Threat Protection.
    3. Settings → Custom DNS → turn it on and enter the NextDNS IPv4 address.
    4. Always connect NordVPN to the same server (not "Quick Connect").

    1. Réglages → Général → VPN et gestion de l'appareil → DNS : sélectionnez N.C.L.B.
    2. Réglages → votre nom → iCloud → Relais privé : désactivez-le.
    3. Si un VPN est connecté : suivez « Maintenir la protection avec NordVPN », ou déconnectez-le pour vérifier.
    4. Activez puis désactivez le mode Avion, puis touchez Vérifier à nouveau.
    1. Settings → General → VPN & Device Management → DNS: choose N.C.L.B.
    2. Settings → your name → iCloud → Private Relay: turn it off.
    3. If a VPN is connected: follow "Keep the protection with NordVPN", or disconnect it to check.
    4. Turn Airplane Mode on and off, then tap Check again.
    1. Mac : Réglages Système → Réseau → VPN et filtres : N.C.L.B doit être actif.
    2. Réglages Système → votre nom → iCloud → Relais privé : désactivez-le.
    3. Désactivez le « DNS sécurisé » de Chrome ou Firefox (voir Installer la protection).
    4. Si un VPN est connecté : suivez « Maintenir la protection avec NordVPN ».
    1. Mac: System Settings → Network → VPN & Filters: N.C.L.B must be active.
    2. System Settings → your name → iCloud → Private Relay: turn it off.
    3. Turn off Chrome's or Firefox's "secure DNS" (see Install the protection).
    4. If a VPN is connected: follow "Keep the protection with NordVPN".
