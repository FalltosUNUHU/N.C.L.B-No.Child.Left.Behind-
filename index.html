Vérification…

N.C.L.B vérifie si la protection est active sur cet appareil.

Installer la protection

Entre le code à 6 caractères donné par ton formateur.

Code de ton formateur :

  1. Touche Autoriser si Safari le demande.
  2. Ouvre Réglages → touche Profil téléchargé tout en haut → Installer.
  3. Reviens ici et touche Vérifier à nouveau.
Verrouiller avec ton formateur

À faire une seule fois, avec ton formateur à côté de toi. Dans Réglages → Temps d'écran → Contenu et confidentialité :

  1. Active l'interrupteur Contenu et confidentialité.
  2. Restrictions de l'App Store → Contenu web → Limiter les sites pour adultes.
  3. Achats dans l'App Store → Installation d'apps → Ne pas autoriser. Plus aucune app Tor, dark web ou de rencontre ne peut être téléchargée.
  4. Retour à Temps d'écran → Utiliser un code Temps d'écran : ton formateur le tape et le garde.
Espace formateur

Tu prépares la protection une fois, puis tu envoies le lien.

  1. Crée un compte gratuit sur my.nextdns.io.
  2. Onglet Parental Control : active Porn, Dating, SafeSearch et YouTube Restricted Mode. Laisse « Block Bypass Methods » désactivé, sinon les VPN seraient bloqués.
  3. Onglet Denylist : ajoute ces domaines, un par un. Touche un domaine pour le copier.
  4. Onglet Settings : active les Logs.
  5. Entre ton ID NextDNS (onglet Setup) pour créer le lien à envoyer :

Le journal : sur my.nextdns.io → onglet Logs → active Blocked Queries Only. Chaque tentative bloquée s'affiche avec la date, l'heure, le domaine et la raison.

Ça ne marche pas ?
  1. Réglages → Général → VPN et gestion de l'appareil → DNS : choisis N.C.L.B.
  2. Réglages → ton nom → iCloud → Relais privé : désactive-le.
  3. Déconnecte ton VPN, active puis désactive le mode Avion, et touche Vérifier à nouveau.
