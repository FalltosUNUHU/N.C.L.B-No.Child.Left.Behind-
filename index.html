NavigateursBrowsers

Chrome et Firefox peuvent contourner le filtre avec leur propre « DNS sécurisé ». Désactive-le : Chrome → Paramètres → Confidentialité et sécurité → Sécurité → Utiliser un DNS sécurisé : désactivé. Firefox → Paramètres → Vie privée et sécurité → DNS via HTTPS : désactivé.

Chrome and Firefox can bypass the filter with their own "secure DNS". Turn it off: Chrome → Settings → Privacy and security → Security → Use secure DNS: off. Firefox → Settings → Privacy & Security → DNS over HTTPS: off.

Garder la protection avec NordVPNKeep the protection with NordVPN

Quand un VPN est connecté, il remplace le filtre. Ce réglage unique, fait par ton formateur, fait passer NordVPN par N.C.L.B : blocage et journal continuent avec le VPN.

When a VPN is connected, it replaces the filter. This one-time setup, done by your trainer, routes NordVPN through N.C.L.B: blocking and the log keep working with the VPN on.

  1. NextDNS : Setup → Linked IP. Note l'adresse IPv4 et copie l'Update URL (sous « Show advanced options »). Garde ce lien privé.
  2. NordVPN : désactive Protection contre les menaces (Threat Protection).
  3. Paramètres → DNS personnalisé → active-le et entre l'adresse IPv4 de NextDNS.
  4. Connecte toujours NordVPN au même serveur (pas « Connexion rapide »).
  1. NextDNS: Setup → Linked IP. Note the IPv4 address and copy the Update URL (under "Show advanced options"). Keep this link private.
  2. NordVPN: turn off Threat Protection.
  3. Settings → Custom DNS → turn it on and enter the NextDNS IPv4 address.
  4. Always connect NordVPN to the same server (not "Quick Connect").
